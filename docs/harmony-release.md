## 二、应用信息填写

- 应用名称：藏币录
- 副标题/一句话：中国纪念币图鉴与收藏账本

- 是否含付费：否

### 应用介绍（可直接粘贴）

> 藏币录收录 1984 年以来中国人民银行发行的普通纪念币、纪念钞与贵金属纪念币图鉴，
> 提供发行量、面额、材质、图案与发行计划查询；登录后可记录自己的藏品数量、成本与冠号，
> 自动计算面值、参考市值与收藏进度，支持导出 CSV 备份。
> 价格与估值均为公开参数估算，不构成投资建议。

## 三、权限与隐私声明

`module.json5` 只声明一个权限：

```json5
{ "name": "ohos.permission.INTERNET", "reason": "$string:perm_internet_reason" }
```

隐私弹窗（`pages/Index.ets` 的 `privacyDialog`）在首次启动时展示，**不同意则退出应用**，
同意前不联网、不读缓存、不读账号。已在应用内提供：

- 隐私政策与用户协议全文（`pages/PrivacyPage.ets`）
- 个人信息收集清单（账号 / 收藏 / 日志 / 反馈，明确不收集位置、通讯录、短信、剪贴板）
- 数据导出（CSV）与删除（单条 / 反馈申请注销）

相册与文件均通过系统选择器（`PhotoViewPicker` / `DocumentViewPicker`）访问，不申请存储权限；
没有后台定位、后台通知、自启动、读取应用列表等敏感能力。

## 五、打包与签名

1. DevEco Studio 打开 `harmony/` → `File → Project Structure → Signing Configs`
   → 勾选 `Automatically generate signature`（需登录华为账号）。
2. `Build → Build Hap(s)/APP(s) → Build APP(s)`，产物在
   `harmony/entry/build/default/outputs/default/`。
3. 命令行只出未签名 HAP（`entry-default-unsigned.hap`），**不能直接安装或上架**，必须走签名。
4. AGC 上传格式：`.app`（Release 签名）。版本号规则：`versionName` 语义化，`versionCode` 单调递增。

## 六、合规风险提示

1. **收藏/资讯类目**：若 AGC 要求提供《互联网信息服务许可证》或内容资质，个人开发者可能被拒；
   建议以「工具-记账」类目申报，弱化资讯属性（应用内不提供新闻流）。
2. **贵金属图片版权**：图片来自中国金币集团公开 CDN，仅展示；如审核质询，需提供授权说明或下架该模块。
3. **UGC**：广场需保留「删除 + 举报 + 审核记录」，服务端已有 `wxsec` 审核与反馈处理。
4. **未成年人**：无付费、无社交私信，评论需登录；建议补充「青少年模式」说明（可选）。

## 七、发布节奏建议

1. 内测：邀请 10–20 位藏友通过「内部测试」通道安装，收集 ArkUI 适配问题（折叠屏、深色模式已强制浅色）。
2. 灰度：先 10% 放量，观察崩溃率与接口错误率（`/api/health` 与日志）。
3. 全量：确认小程序与鸿蒙端数据一致（同一账号互查藏品数量与市值）。
